# C3: Publish the dataset summary as a shareable page

**Track:** C   **Depends on:** C2   **Parallel-safe:** yes

Turn the tables and figures into one page the lab can open and use to decide which
species to work on.

**Acceptance.** A published artifact with the species table sortable and filterable, the
figures, and plain statements of the known limits: counts are floors because of the
tax_tree blind spot (A2), and run counts are not independent strain counts for clonal
species like *C. auris*.
